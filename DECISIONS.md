## 2026-05-21 — ABI indexer (Forge + Blockscout strict dual-source)

Context: Preflight decode relied on hardcoded ERC20 selectors and `knownSelectors.ts`; deployed demo contracts expose many more functions (e.g. `mint`, `checkSwapDeviation`).

Decision:
- Committed offline index: `apps/web/src/data/abi-index.json` + `abi-index.meta.json`, generated by `npm run sync:abi-index` (`scripts/sync-abi-index.mjs`).
- **Strict match:** Foundry `contracts/out/*.json` ABI must equal Blockscout `getabi` for each address in `deployments/base-sepolia.json`; sync exits 1 on drift.
- Runtime: `lib/indexer/abiIndex.ts` + `decodeWithIndexer.ts`; decoder tries indexer **before** ERC20 fast-path when `intent.to` is indexed.
- `GET /api/indexer` exposes contract list and sync metadata (no secrets).
- `ABI_INDEX_SKIP_BLOCKSCOUT=1` for offline regen from forge only (not release verify).

Reason: Full-function decode on known demo contracts without runtime Blockscout calls; operator-verified ABI parity.

Impact: `transactionDecoder.ts`, `decodeCallData.ts`, `previewEnrichmentAdapter.ts`, `contractRegistryAdapter.ts`, `scripts/verify-backend.sh`, `tests/curl-abi-index.sh`.

Owner: backend-rpc

## Initial decisions

### Aegis is a wrapped RPC for MVP

Context: Full RPC node infra is too large for hackathon.
Decision: Build `/api/rpc` wrapper with passthrough and transaction screening.

Decision: Use `ChainlinkPriceAdapter` as first adapter, not core product.
